この**Inmuebles24 Mexico Properties Dataset Sample**には**1,236件のレコード**が含まれており、**Bright Data API**を使用して抽出されました。

## データポイント

| Field Name | Description |
|------------|-------------|
| `url` | Inmuebles24上の物件掲載ページに対応する一意のWebアドレス。 |
| `Title` | 売主によって提供された物件掲載のメインタイトル。 |
| `GeneratedTitle` | 物件タイプや面積などの詳細を要約した、システム生成のタイトル。 |
| `Description` | 特徴や所在地を含む物件の詳細説明。 |
| `Seller` | 物件を販売している個人または組織の名前または識別子。 |
| `Precio` | 指定された通貨で表示された物件価格。 |
| `Publicado_hace` | 物件が掲載されてからの経過時間（日数）。 |
| `CreatedDate` | プラットフォーム上で物件掲載が作成された日付。 |
| `Visualizaciones` | 物件掲載が閲覧された回数。 |
| `Dimension_terreno` | 物件の土地総面積（平方メートル）。 |
| `Dimension_propiedad` | 物件の建築面積または延床面積（平方メートル）。 |
| `Estacionamiento` | 物件に付属する駐車スペースの数。 |
| `Banos` | 物件内のバスルームの数。 |
| `Dormitorios` | 物件のベッドルーム数。 |
| `Antiguedad` | 通常は年数で表される物件の築年数。 |
| `pictures` | 掲載に含まれる物件画像へのリンクまたは識別子。 |
| `videos` | 掲載に含まれる物件動画へのリンクまたは識別子。 |
| `Tipo_de_inmueble` | アパート、住宅、商業スペースなどの物件タイプ。 |
| `Tipo_de_operacion` | 売買や賃貸などの取引タイプ。 |
| `Tipovendedor` | オーナーや不動産仲介業者などの売主タイプ。 |
| `Phone1` | 物件に関する問い合わせ用の主な連絡先電話番号。 |
| `whatsApp` | インスタントメッセージでの問い合わせ用WhatsApp連絡先番号。 |
| `Operacion` | 購入や賃貸借などのオペレーションタイプを指定。 |
| `Region` | 物件が所在するより広域の地理的地域。 |
| `Zona` | 物件の具体的なゾーンまたは近隣地域。 |
| `Ciudad` | 物件が所在する都市。 |
| `Provincia` | 物件が所在する州または県。 |
| `Direccion` | 物件の完全な住所。 |
| `Superdestacado` | 掲載がプラットフォーム上で注目掲載または強調表示されているかを示す。 |
| `postingId` | 物件掲載の一意の識別子。 |
| `postingCode` | 物件掲載を表すコードで、内部的に使用されることが多い。 |
| `publisher` | 掲載が広告掲載されている発行元またはプラットフォーム。 |
| `premier` | 掲載がプレミアステータスまたは強化された可視性を持つかを示す。 |
| `URL` | 物件掲載への直接URL。 |
| `aviso_finalizado` | 掲載が完了または終了しているかを示す。 |
| `currency` | 物件価格が表示されている通貨。 |
| `latitude` | 物件の地理的緯度座標。 |
| `longitude` | 物件の地理的経度座標。 |


## ユースケース

### 1. 不動産市場分析
メキシコにおける物件トレンドと価格を分析し、不動産の専門家がデータに基づいた投資判断を行えるよう支援します。

### 2. 競合ベンチマーキング
さまざまな地域の掲載情報を比較し、競争上のポジショニングを評価して、物件マーケティング戦略を最適化します。

### 3. 都市開発計画
地理データと物件データを活用して、都市計画担当者による持続可能で効率的な都市インフラ設計を支援します。
